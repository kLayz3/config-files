- fastfetch
- cmatrix
- cargo install rustlings


### Few other cool gimmicks:
- https://github.com/bjarneo/omarchy-pulsar-theme
- omarchy plugin add https://github.com/TerrifiedBug/omascreensaver.git --enable
- omarchy plugin add https://github.com/SirJul1337/omarchy-lock-explorer.git --enable

For the lock customisation: `omarchy-shell lock explore` followed by `O` (shift-o), then `D` (shift-d) and
Media -> Add -> Png, and do the customisation as wanted.
